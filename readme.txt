Media library folders by Clear pH. A data-compatible replacement for FileBird.

== Description ==

Reads and writes FileBird's own tables (`{prefix}fbv`, `{prefix}fbv_attachment_folder`), so a site can switch from FileBird to CPH FileBird with no migration. Do not run both at once; CPH FileBird pauses itself while FileBird is active.
